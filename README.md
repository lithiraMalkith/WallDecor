# Ceylon Wall Decor Storefront

A frontend-only storefront demo built with Next.js 16, React 19, TypeScript, Tailwind CSS 4, GSAP and Lucide icons.

## Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Included

- Animated, responsive home page
- Product catalog, search, room filters and sorting
- Product size and frame selection with live pricing
- Persistent browser cart, drawer and cart page
- Guest Cash on Delivery checkout simulation
- Local order confirmation and tracking demonstration
- Custom-order upload form
- Gallery, about, contact, size guide, FAQ and policy pages
- Local optimized image assets; no credentials required

## Demo limitations

This package is storefront UI only. Cart and simulated orders are kept in the browser. The contact, custom request and tracking forms demonstrate their final interaction states but do not send data. Connect your own secure database/API before accepting real orders, and always recalculate prices on the server.
